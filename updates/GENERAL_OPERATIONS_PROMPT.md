# پرامپت جنرال و راهنمای عملیاتی Codein

این سند به عنوان مرجع اصلی تمام ایجنت‌ها و مدل‌های هوش مصنوعی برای کار در این محیط عمل می‌کند.

## ۱. اصول اولیه و بررسی پیش‌نیازها
- پیش از اجرای هرگونه اسکریپت یا دستور، وجود پوشه‌ها، فایل‌ها و دسترسی‌های لازم را بررسی کنید.
- از اجرای دستورات مخرب یا تغییرات مستقیم روی شاخه اصلی (`main`) بدون ساخت شاخه جدید (`feature branch`) خودداری کنید.

## ۲. ساختار اجرایی پوشه updates
- تمام اسکریپت‌ها و پچ‌های جدید در پوشه `updates/` قرار می‌گیرند.
- قبل از اجرای هر اسکریپت درون این پوشه، مجوز اجرای آن را بررسی و تنظیم کنید:
  ```bash
  chmod +x updates/<script_name>
  ```
- خروجی و خطاهای هر دستور را با دقت بررسی کرده و در صورت بروز خطا، از ادامه‌ی کورکورانه‌ی عملیات جلوگیری کنید.

## ۳. دستورالعمل تعامل با گیت (Git)
- تغییرات را ابتدا در شاخه محلی تست کرده و سپس کامیت کنید:
  ```bash
  git checkout -b update-fix-branch
  git add .
  git commit -m "update: اعمال بهبودها و اسکریپت‌های جدید"
  git push origin update-fix-branch
  ```
